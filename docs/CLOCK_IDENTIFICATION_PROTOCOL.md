# Noisy local-band identification protocol

Exploratory extension, written before the new screen. Use sizes 16/64, three
mechanisms per size, raw gates uniform [.2,.6] and survival .95/.8/.5. Observe
distance-two and distance-three bands under the same two alternating loads.
Noise SD is 0/.0001/.001/.01, with independent Gaussian noise in every observed
scalar. Use one simultaneous 95% Gaussian union bound over all observed bands.
Propagate interval boxes through local gate inversion and the shared-clock
ratio; intersect clock constraints over both views and all locations. Retain
empty sets and broad uncertainty. No clipping away of rejection is allowed.

Predict clean held-out uniform loading with no cut, a left cut and simultaneous
left/right cuts. Box monotonicity gives conservative prediction intervals.
Record clock error, clock/held-out coverage, mean prediction width and matched
point errors versus the static marginal-gate model. The noisy experiment is
still simulated. Do not claim recovery of physical kinetics from observational
biological data. A nongeometric mixture of s=.3/.95 at equal weight is an explicit
model-mismatch control at the same noise levels.

Payoff gate: mean absolute clock error below .05 at SD .001, at least halving
held-out message RMSE against the static model in that condition, and retained
uncertainty accounting. A pass supports the bounded identification method;
it does not establish a better learning architecture or universal model validity.
